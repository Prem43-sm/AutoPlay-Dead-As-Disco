# Future YOLO dataset: player/enemy v2

This is an empty, versioned destination schema for the proposed two-class
detector. It is separate from `data/dataset/`, whose six-class configuration
and existing labels are the immutable legacy source for this migration.

No images or labels have been copied into this directory. See
[`../../docs/DATASET_TAXONOMY_MIGRATION.md`](../../docs/DATASET_TAXONOMY_MIGRATION.md)
for manual review, approvals, the migration tool, and session-level split
planning. A label is eligible only after a reviewer explicitly approves its
individual player/enemy box and records the source image/label checksums.
